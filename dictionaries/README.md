# Русскоязычные словари замен

Пакет содержит четыре детерминированных строго двунаправленных набора.

| Набор | Логических пар | Направленных записей |
|---|---:|---:|
| alpha | 5 985 | 11 970 |
| beta | 6 017 | 12 034 |
| gamma | 6 018 | 12 036 |
| omega | 1 267 | 2 534 |

## Файлы

- `mappings/*.json` — готовые плоские двунаправленные mappings вида `{source: target}`.
- `pairs/*.csv` — каждая логическая пара записана один раз как `source,target`.
- `audit/*_audit.csv` — данные для проверки морфологии, частотности и семантических veto.
- `manifest.json` — статистика построения и SHA-256 файлов.
- `verification_summary.json` — независимая финальная проверка результатов.
- `validate_mappings.py` — быстрая структурная проверка JSON.
- `tools/build_ru_mappings.py` — воспроизводимый генератор.

## Гарантируемые инварианты

Внутри каждого набора каждое слово встречается ровно в одной логической паре; отсутствуют самозамены, цепочки, коллизии и циклы длиной больше двух. Для любой записи выполняется `mapping[mapping[word]] == word`.

Уникальность слов гарантируется **внутри отдельного mapping**. Повторное использование слов между `alpha`, `beta` и `gamma` намеренно: это sibling reseed-варианты одного высокочастотного словарного пула. При этом ни одна точная логическая пара между четырьмя наборами не повторяется.

## Проверка

```bash
python validate_mappings.py
```

Подробности методики, ограничения автоматической лингвистической проверки и условия источников данных приведены в `QUALITY_REPORT.md` и `DATA_SOURCES_AND_LICENSES.md`.
